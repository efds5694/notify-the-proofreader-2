先导入工作手册

首次使用需要导入手册。程序只会为每轮请求选取少量相关章节。

选择或拖入手册文件

支持 UTF-8 编码的 Markdown、TXT，文件需为 100 字至 1 MB。标题结构会用于准确匹配相关章节。

整本手册不会上传。每次生成时，浏览器只会把本地检索到的相关摘录发送给当前 AI 接口。

如何使用明晰

从材料到可发送通知，只需要选择模式、提供事实并核对结果。

首次使用会依次查看本帮助、导入本地工作手册并配置模型接口。完成后，这些内容都会保存在当前浏览器。

01选择合适的模式
  • 编写：提供不少于 50 字的事实材料。
  • 修改：分别粘贴原通知和修改要求。
  • 检查：只需粘贴需要检查的通知。
02导入工作手册

支持 Markdown 和 TXT。整本手册只保存在本机，每轮最多向 AI 发送 4,000 字相关摘录。

03配置模型接口

填写 OpenAI 兼容 Base URL、API Key 和模型名称，也可使用 OpenAI 或 DeepSeek 预设。三种模式的系统提示词可分别修改。

04核对并继续对话

回复下方会显示字符数、模型和接口提供的 token 用量。可复制单条回复或整个对话，历史自动保存在本机。

Ctrl / ⌘ + Enter 生成或发送 Enter 在输入框中换行 Esc 关闭普通弹窗
